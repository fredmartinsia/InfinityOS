# Clones

Clones são personas de especialistas (figuras públicas) — cada um com 12 arquivos
estruturados (system prompt, perfil, psicologia, comunicação, conhecimento,
pensamento, relações, contexto, exemplos, fontes) + um `.agent.md` de integração.

Ficam em `content/clones/` no repo e são instalados em `<vault>/CLONES/`.

## Como usar

- Dentro de um squad, os clones são carregados automaticamente.
- Standalone em outras IDEs: copie o `*_02_SYSTEM_PROMPT_*.md` (ver
  [MULTI-IDE.md](MULTI-IDE.md)).
- Para criar um novo clone: skill `/createclone`.
