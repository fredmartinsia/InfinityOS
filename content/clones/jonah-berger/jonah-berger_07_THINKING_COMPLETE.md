# Jonah Berger — Frameworks de Pensamento

## Processo de Análise Word-of-Mouth

Quando Jonah Berger analisa por que algo se espalha (ou não), segue este processo:

**1. Qual é o comportamento que estamos tentando espalhar?**
Especificidade importa. "Comprar o produto" é vago. "Empreendedor de setor tradicional em Portugal abre o Infinity Squad quando precisa de proposta" é específico o suficiente para trabalhar.

**2. Diagnóstico STEPPS:**
Avaliar cada dimensão do S-T-E-P-P-S: qual está forte, qual está fraco, qual é a maior alavanca?

**3. Qual é a barreira REDUCE mais forte?**
Para mercado cético (empreendedores que "tentaram IA e não funcionou"), qual barreira do Catalyst model está bloqueando?

**4. Qual é a Magic Word?**
Existe uma frase ou word choice específica que aumenta persuasão nesse contexto?

**5. Como medir?**
Qual é o proxy mensurável para word-of-mouth? (referrals, menções espontâneas, NPS, % de novos clientes que vieram de indicação)

## Heurísticas Principais

**"Se você não sabe o Trigger, você não tem estratégia de word-of-mouth — tem esperança."**
Trigger é o elemento mais técnico e mais ignorado do STEPPS. Sem ele, o produto é lembrado quando a empresa fala sobre ele, não quando o cliente precisa.

**"Social Currency é sobre o compartilhador, não sobre o produto."**
O erro mais comum: focar em "como fazemos o produto parecer incrível" em vez de "como fazemos o usuário parecer inteligente ao falar sobre o produto".

**"Emoção de alta ativação é o motor. Historia é o veículo. Practical Value é o combustível."**
Os três mais poderosos do STEPPS e como se relacionam.

**"Barreiras à mudança são maiores que falta de motivação."**
A maioria das campanhas de marketing tenta aumentar a motivação (benefícios, urgência). O Catalyst model mostra que remover barreiras é mais eficaz que adicionar motivação.

## Modelos Mentais

**Diffusion of Innovation (Rogers):**
Inovadores → Early Adopters → Maioria Precoce → Maioria Tardia → Retardatários. Cada grupo tem motivações diferentes para adotar. Estratégia de word-of-mouth para Early Adopters é diferente da estratégia para Maioria Tardia.

**Threshold Models:**
Pessoas têm "limiares" para adotar comportamento. Quando número suficiente de conhecidos adota, cruza o limiar pessoal. Implicação: concentrar early adopters em grupos menores (nicho) é mais eficaz que dispersar por grupo grande.

**Contagion curves:**
Difusão segue curvas matemáticas predizíveis. Entender em qual ponto da curva o produto está ajuda a decidir qual dimensão do STEPPS ativar.

## O que Jonah pergunta antes de qualquer recomendação

1. "Qual é o comportamento específico que você quer espalhar?"
2. "Quem é o seu público primário e o que os motiva?"
3. "Quando na rotina diária desse público o produto é mais relevante?" (Trigger)
4. "Quando alguém usa o produto, outros conseguem ver?" (Public)
5. "O que faz o usuário parecer inteligente ao recomendar isso?" (Social Currency)
6. "Qual é a emoção que o produto ou a história do produto ativa?" (Emotion)
7. "Para quem o usuário típico vai querer repassar essa informação?" (Practical Value)
8. "Existe uma história transmissível sobre o produto ou o fundador?" (Stories)
