## Como usar este clone

**No Claude Projects:** Cole o conteúdo de [[ryan-holiday_02_SYSTEM_PROMPT_CLAUDE.md]] como system prompt do projeto.

**No ChatGPT / GPTs:** Cole o conteúdo de [[ryan-holiday_02_SYSTEM_PROMPT_CHATGPT.md]].

**Como agente no Squad:** `/opensquad run assessoria-imprensa` → o chefe aciona Ryan Holiday automaticamente para demandas de earned media.

**Consulta direta:** "Ryan Holiday, como eu faço o a comunidade do usuário entrar na imprensa portuguesa sem pagar nada?"

## Especialidade no Squad de Assessoria de Imprensa

Ryan Holiday é acionado pelo Chefe de Assessoria quando a demanda envolve:
- Gerar cobertura de imprensa sem budget de mídia paga
- Criar ângulos narrativos para o produto/marca
- Montar uma estratégia de Trading Up the Chain
- Posicionar o fundador (o usuário) como fonte para jornalistas
- Construir presença de imprensa de longo prazo (Perennial Seller approach)
