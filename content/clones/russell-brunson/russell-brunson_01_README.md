## 🚀 Como Usar Este Clone

### Opção 1: GPT Personalizado (OpenAI)
1. Acesse chat.openai.com → "Explore GPTs" → "Create"
2. Cole conteúdo de `russell-brunson_02_SYSTEM_PROMPT_CHATGPT.md` em Instructions
3. Faça upload dos arquivos `03` até `11` em Knowledge (9 arquivos)
4. Teste: "Como crio um funil para meu produto de R$997?"

### Opção 2: Claude Project
1. Crie novo projeto: "Clone Russell Brunson v1"
2. Cole conteúdo de `russell-brunson_02_SYSTEM_PROMPT_CLAUDE.md` em Custom Instructions
3. Faça upload dos arquivos `03` até `11` como knowledge base
4. Teste e use no Squad de Copy & Oferta

- Papel principal: criação de funis, estruturação de Hook-Story-Offer, diagnóstico de conversão
- Funciona em pipeline com Alex Hormozi (ofertas) e Joanna Wiebe (copy de alta conversão)
- **Exemplos de projetos:** a comunidade do usuário, qualquer negócio de infoprodutos, memberships, serviços B2B, SaaS, e-commerce com funil

## ⚠️ Limitações Conhecidas

**O clone FAZ:**
- ✅ Estrutura Hook-Story-Offer para qualquer formato
- ✅ Diagnostica funis por camadas (hook → story → offer)
- ✅ Aplica Value Ladder a qualquer negócio de serviço/conhecimento
- ✅ Cria Epiphany Bridges e roteiros de webinar
- ✅ Mapeia Dream 100 para audiências específicas

**O clone NÃO FAZ:**
- ❌ Conselhos sobre enterprise sales (ciclo longo, múltiplos stakeholders)
- ❌ B2C físico complexo (logística, supply chain)
- ❌ Mercados regulados (financeiro, farmacêutico)
- ❌ Recomendações de ferramentas sem revelar viés para ClickFunnels
- ❌ Conselhos sobre produto antes de diagnosticar o funil
