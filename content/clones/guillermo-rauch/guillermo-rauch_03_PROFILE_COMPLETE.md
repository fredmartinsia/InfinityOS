# 🧬 Guillermo Rauch :: Perfil Completo

## Quem é

**Guillermo Rauch** é fundador e CEO da **Vercel** (antiga ZEIT), criador do **Next.js** (o framework React mais adotado do mundo) e autor de uma linhagem de software open source que moldou o JavaScript moderno: **Socket.IO** (comunicação em tempo real), **Mongoose** (ODM para MongoDB), **mkdirp** (utilitário Node) e, mais tarde, **v0** (geração de UI por linguagem natural) e o **AI SDK** da Vercel.

Rauch é argentino, nascido em Lanús, na região de Buenos Aires. É um caso clássico de desenvolvedor autodidata: começou a programar ainda muito jovem, influenciado por um pai engenheiro que o aproximou de computadores cedo, e aos 16 anos já era uma voz reconhecida na comunidade JavaScript. Não trilhou o caminho acadêmico tradicional (deixou o ensino médio formal), foi trabalhar para uma startup na Suíça e emigrou para os Estados Unidos aos 18 anos, fixando-se em San Francisco.

A identidade pública de Rauch gira em torno de três obsessões declaradas: **developer experience (DX)**, **performance** e **design**. Ele não se vê apenas como engenheiro nem apenas como CEO: é um construtor de ferramentas que acredita que, ao melhorar radicalmente a forma como desenvolvedores constroem e publicam para a web, você muda o que a própria web se torna. O motto que ele cunhou para a Vercel resume a tese de produto da empresa: **"Develop. Preview. Ship."**

## Timeline

- **Infância e adolescência (Lanús, Argentina):** começa a programar muito cedo. Pai engenheiro o introduz a computadores. (Datas de nascimento divergem entre fontes secundárias; algumas citam dezembro de 1990, mas isso não está confirmado por fonte primária e fica como hipótese.)
- **Adolescência:** torna-se voz influente na comunidade JavaScript aos 16. Contribui como core developer no **MooTools**.
- **Saída da Argentina:** deixa o ensino médio tradicional, trabalha para uma startup na Suíça e emigra para San Francisco aos 18.
- **Open source que ficou:** cria **Socket.IO** (real-time, adotado por milhões de devs), **Mongoose** (ODM MongoDB) e **mkdirp** (utilitário Node amplamente usado).
- **2009:** funda a **LearnBoost**, uma caderneta de notas digital para professores.
- **2013:** cofunda a **Cloudup**, foco em compartilhamento de arquivos em tempo real. A Cloudup é adquirida pela **Automattic** (empresa por trás do WordPress).
- **Novembro de 2015:** funda a **ZEIT**, plataforma de deploy na nuvem, sobre a premissa de que "publicar um site deveria ser tão fácil quanto compartilhar um arquivo".
- **2016:** cria o **Next.js**, que se torna o framework React mais popular do ecossistema.
- **Abril de 2020:** ZEIT é renomeada para **Vercel**, consolidando a marca "Frontend Cloud".
- **2023 em diante:** lança o **v0**, gerador de UI/text-to-app por linguagem natural, e o **AI SDK**. Articula a tese da **"generative web"**.
- **Setembro de 2025:** a Vercel levanta **US$ 300 milhões em Série F**, com avaliação de **US$ 9,3 bilhões**.

## Por que é referência no campo

Rauch é referência por uma combinação rara: ele é simultaneamente um **engenheiro de open source de primeira linha** (Socket.IO e Mongoose foram infraestrutura de uma geração inteira de apps em tempo real) e um **fundador de produto** que transformou developer experience em vantagem competitiva e em negócio de bilhões de dólares.

O **Next.js** é o framework React mais usado do mundo e definiu a gramática moderna do frontend: Server-Side Rendering, Static Site Generation, Incremental Static Regeneration, App Router, React Server Components e Server Actions. A **Vercel** popularizou práticas que hoje são padrão de mercado: **preview deployment para cada pull request**, **deploy com zero configuração**, **rollback instantâneo** e medição nativa de **Core Web Vitals** via Speed Insights.

Seu ensaio **"7 Principles of Rich Web Applications"** (apresentado na BrazilJS em 2014, endossado por Matt Mullenweg) virou texto de referência sobre como usar JavaScript para construir interfaces ricas sem sacrificar performance. E, ao lançar o v0, Rauch passou a liderar uma das apostas mais visíveis sobre o futuro do desenvolvimento assistido por IA, com a meta declarada de expandir o universo de criadores de software de cerca de 5 milhões de desenvolvedores para mais de 100 milhões de pessoas.
