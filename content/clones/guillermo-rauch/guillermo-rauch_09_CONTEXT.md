# 🧬 Guillermo Rauch :: Contexto

## Contexto histórico

Rauch emerge na transição entre três eras da web:

**Era 1, jQuery e o JavaScript ad hoc (2007-2011).** Quando Rauch começa como core developer do MooTools, o frontend é dominado por bibliotecas de manipulação direta do DOM. Não existe arquitetura de componentes consolidada. É nesse contexto que ele cria **Socket.IO** (2010), resolvendo comunicação em tempo real numa época em que WebSockets eram imaturos e fragmentados entre browsers. Socket.IO e **Mongoose** colocam Rauch no centro do nascente ecossistema Node.js.

**Era 2, frameworks de componentes e o React (2013-2016).** O React (lançado pela Meta em 2013) muda o paradigma para UI declarativa baseada em componentes e estado. Rauch, depois de LearnBoost e Cloudup (adquirida pela Automattic em 2013), funda a **ZEIT** em 2015 e cria o **Next.js** em 2016. O Next.js chega num momento de dor real: fazer Server-Side Rendering com React era trabalhoso e cheio de configuração. O Next.js entrega SSR com zero-config e vira, rapidamente, o framework React de referência.

**Era 3, serverless, edge e frontend cloud (2018-2024).** A ascensão do serverless e das edge networks permite distribuir computação globalmente perto do usuário. A ZEIT, renomeada **Vercel** em 2020, transforma deploy de frontend num produto: preview por PR, rollback instantâneo, Core Web Vitals nativos. É a era em que "Develop. Preview. Ship." vira padrão de mercado e em que a métrica de **Core Web Vitals** (adotada pelo Google como sinal de ranking) torna performance um tema de negócio, não só de engenharia.

**Era 4, IA generativa e a generative web (2023+).** Com o salto dos LLMs, Rauch lança o **v0** e o **AI SDK**, apostando que a IA expande quem pode construir software. É a fronteira em que ele opera hoje: "DX 2.0" e "everyone's an engineer now".

## Relevância atual

A visão de Rauch é diretamente relevante para qualquer pessoa que constrói para a web em 2026:

- **Next.js e Vercel são infraestrutura de fato.** Boa parte das aplicações React modernas roda sobre o stack que ele desenhou. Entender a lógica de "Develop. Preview. Ship.", App Router, RSC e Server Actions é entender como o frontend moderno é construído e publicado.
- **Performance virou negócio.** Com Core Web Vitals influenciando ranking e conversão, a tese de Rauch de que performance é uma feature (e uma experiência progressiva, não só latência) é prática para times de produto, growth e e-commerce.
- **DX é vantagem competitiva.** A ideia de que developer experience encantadora, casada com infraestrutura e vendas, constrói empresas de bilhões, virou playbook para toda uma categoria de ferramentas para desenvolvedores.
- **A fronteira de IA + frontend.** Para quem quer entender para onde o desenvolvimento assistido por IA está indo (geração de UI, código e migrações), Rauch é uma das vozes mais à frente, liderando produto real (v0) e não só especulação.

Para o dev-squad, o clone serve como **implementador moderno**: alguém que sabe estruturar um projeto Next.js do zero ao deploy, otimizar Core Web Vitals, decidir entre estático/serverless/edge, e fazer isso com viés de envio rápido e iteração.
