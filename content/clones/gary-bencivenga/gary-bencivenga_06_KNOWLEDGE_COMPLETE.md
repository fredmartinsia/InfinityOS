## 6 FRAMEWORKS FUNDAMENTAIS

### Framework 1: Persuasão Bencivenga

```
URGENT PROBLEM
     +
UNIQUE PROMISE
     +
UNQUESTIONABLE PROOF
     +
USER-FRIENDLY PROPOSITION
     =
CONVERSION
```

**Como aplicar:**

**1. Problema Urgente**
- Qual é o problema que mantém seu prospect acordado às 3am?
- Quanto mais específico, maior a resposta
- Problema deve parecer irresolúvel sem sua solução

**2. Promessa Única**
- Por que sua solução é diferente de tudo mais?
- Qual é o mecanismo único?
- Não é "melhor" — é diferente de forma que importa

**3. Prova Irrefutável**
- Testimoniais específicos com números
- Estudos científicos com fonte
- Demostrações e provas
- Garantias que eliminam risco

**4. Proposição Amigável**
- Oferta clara e simples
- Próximos passos óbvios
- Remove todas as fricções

---

### Framework 2: Técnica Credo

**Princípio:** "Stand for something and you'll never stand alone."

Define e comunica o que você acredita ANTES de vender.

```
"Eu acredito que [valor 1]..."
"Eu acredito que [valor 2]..."
"E é por isso que criamos [produto] para quem [perfil]."
```

**Por que funciona:**
- Pré-qualifica o prospect (valores alinhados)
- Cria confiança antes da venda
- Diferencia por valores, não features
- Atrai clientes certos, repele errados

---

### Framework 3: Regra 80/20

80% do sucesso depende de 3 elementos:

```
OFERTA (40% do resultado)
├─ O que você vende
├─ Por qual preço
├─ Com qual garantia
└─ Com quais bônus

LISTA/AUDIÊNCIA (40% do resultado)
├─ Quem recebe a mensagem
├─ O que já quer
└─ Nível de consciência do problema

COPY (20% do resultado)
└─ Como comunica ao prospect
```

**Implicação:** Oferta medíocre + Lista ótima > Copy ótimo + Lista errada

---

### Framework 4: Pesquisa 7x

Coleta **7 vezes mais pesquisa** do que acha que vai precisar.

**Processo:**

**Pesquisa de Produto**
- O que faz exatamente?
- Como funciona (mecanismo)?
- Quais resultados foram documentados?
- O que diferencia de alternativas?

**Pesquisa de Mercado**
- Quem são os heavy users (20% que geram 80%)?
- O que eles querem mais do que qualquer coisa?
- Quais são objeções específicas?
- Qual linguagem usam para descrever problema?

**Pesquisa Competitiva**
- O que concorrentes prometem?
- O que NÃO prometem (gap seu)?
- Quais claims são provados vs. retórica?

---

### Framework 5: "O Que Realmente Estamos Vendendo?"

Identifique a **transformação real**, não o veículo.

**Exemplos:**
- Sementes de grama → Gramado verde que faz vizinhos invejarem
- Curso de inglês → Confiança profissional e social
- Suplemento de sono → Energia, clareza, performance
- Software financeiro → Controle e paz de espírito
- Academia → Admiração e autoestima

**Regra:** Sempre venda o destino, não o veículo.

---

### Framework 6: Copy como Vendedor Multiplicado

**Conceito:** "Advertising is multiplied salesmanship."

Um vendedor fecha 1 venda por vez. Uma peça de copy fecha 1.000 simultaneamente.

**Implicação:** Cada decisão de copy é como treinar um exército de vendedores. O que o melhor vendedor diria?

## ESTRUTURA DE SALES LETTER CLÁSSICA

```
HEADLINE — Promessa específica + curiosidade

DECK COPY — 2-3 linhas expandindo headline

LEAD — Urgência do problema + identificação

CREDO — Valores antes da venda (opcional)

CREDENCIAL — Por que você pode fazer essa promessa

PROMESSA PRINCIPAL — O que vai acontecer

MECANISMO — Como funciona (razão científica)

PROVA — Testimoniais + estudos + demos + números

BULLETS — Curiosidades específicas

OFERTA — Produto + bônus + preço + garantia

CTA — Ação clara, urgente, simples

P.S. — Reforço do benefício mais poderoso
```

## PADRÕES DE HEADLINES

### Fórmula Base
```
[Resultado Específico] em [Prazo Específico] — [Mecanismo Único]
```

### Variações Testadas
- **Curiosidade:** "O segredo [específico] que [benefício inesperado]..."
- **Notícia:** "Finalmente: [solução para problema antigo]"
- **Pergunta:** "Você [problema]? Aqui está por quê..."
- **Testemunhal:** "'[Resultado dramático específico]' — [Nome], [Contexto]"
- **Problema:** "[Problema específico] sem [solução tradicional]?"

---

## PADRÕES DE BULLETS/FASCINATIONS

### Estrutura Base
```
[O quê] — sem revelar o [como] (p. XX)
```

### Checklist
- [ ] Específico (número, prazo, nome, lugar)?
- [ ] Cria curiosidade genuína (revela benefício, esconde método)?
- [ ] É crível (não parece exagerado)?
- [ ] Conecta com desejo real?
- [ ] Usa linguagem do prospect?

## SISTEMA DE PROVA (Hierarquia)

1. **Resultados verificáveis com números específicos**
   > "Maria P. perdeu 23 libras em 47 dias."

2. **Estudos científicos com fonte**
   > "Pesquisa Universidade Johns Hopkins (2019) mostrou..."

3. **Demonstração visual/demo**

4. **Endosso de especialista credível**

5. **Lógica de 'razão por que'**

6. **Depoimento geral sem números**
