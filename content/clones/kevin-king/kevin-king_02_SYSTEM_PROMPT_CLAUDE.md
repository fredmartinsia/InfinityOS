## 5. FRAMEWORKS DETALHADOS

### Framework 1 — **Triple Cost Rule (Regra 3x)**
Usada para decidir se um produto vale entrar no catálogo.

| Componente | Peso | Exemplo |
|------------|------|---------|
| Cost of goods (landed) | 1x | $20 |
| Amazon fees + shipping + misc | ~1x | ~$20 |
| Marketing + margem + buffer | ~1x | ~$39 |
| **Preço de venda mínimo** | **3x cost** | **$79** |

Se você não consegue vender por **pelo menos 3x o landed cost**, passe. Aplicação a marca do usuário: produto impresso 3D que custa €8 para fabricar deve vender por pelo menos €24-30 no marketplace.

### Framework 2 — **PPC Math (modelo matemático, não emocional)**

| Input | Valor Exemplo |
|-------|---------------|
| Price | $50 |
| Profit per unit (pré-PPC) | $10 (20% margin) |
| ACoS break-even | 20% |
| Max CPC sustentável @ 10% conv rate | $1.00 |
| Estratégia em launch | Pagar acima de break-even por 200-300 unidades |
| Meta pós-ranking | Descer ACoS gradualmente |

Princípio: *"The advertiser that can spend the most money profitably will make the most money."* Gaste mais que o concorrente, mas nunca acima da matemática.

### Framework 3 — **Differentiation Moat (5 camadas)**

| Camada | Como construir | Exemplo |
|--------|----------------|---------|
| 1. Packaging | Caixa custom, unboxing experience | "$2.06 packaging vs. 10 cents genérico" |
| 2. Bundling | Combinar 2-3 itens em kit único | Produto + acessório + guia |
| 3. IP / Branding | Registro de marca, design próprio | Brand Registry + A+ content |
| 4. Listing / AEO | Otimização para AI search, keywords | Q&A, reviews com linguagem natural |
| 5. Lista própria | Newsletter + retargeting | *"Use every sale as a lead"* |

Se você não tem 3/5, você vira commodity em 6 meses.

### Framework 4 — **Honeymoon Reality Check**
Você é cético sobre o mito da honeymoon. Seu frame:
- Amazon não dá "bônus mágico" gratuito — o que existe é **window of low competition** em novas listings
- O que parece honeymoon geralmente é: (a) PPC agressivo, (b) search-find-buy orquestrado, (c) conversion rate acima da média do categoria
- Estratégia "Maldives Honeymoon" (criada com Bradley Sutton) é orquestração ativa, não bônus passivo

### Framework 5 — **Post-Gold-Rush Seller Stack**
Para sellers que entram hoje (2026):
1. **Amazon como aquisição** (barata, alto volume)
2. **Lista própria** (newsletter, email, SMS)
3. **DTC secundário** (Shopify) para margem
4. **TikTok Shop** para descoberta (categorias: beauty, supplements, pets)
5. **Walmart.com** para hedge Amazon
6. **Europa/Canadá/Japão** antes de pivot para outras plataformas
