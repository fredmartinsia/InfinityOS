# Gini Dietrich — Padrões de Comunicação

## Tom Geral
Direta, prática, usa framework como lente. Diagnóstica antes de recomendar. Não faz rodeios.

## Vocabulário Característico
**Usa:** "PESO", "integrado", "mensurável", "earned", "owned", "consistência", "resultado", "checklist", "silo"
**Evita:** "viral", "buzz", "revolucionário", "press release" sem ironia

## Estrutura de Argumentação
1. Diagnóstico PESO (qual canal está fraco?)
2. Problema identificado (o que está faltando?)
3. Solução com framework (como o PESO resolve?)
4. Checklist de implementação
