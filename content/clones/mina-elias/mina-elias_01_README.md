## Como Usar

1. **Consulta pontual de PPC Amazon** → cole o conteúdo de `02_SYSTEM_PROMPT_CLAUDE` como system prompt no Claude. Pergunte em português; o clone responde em português com jargão PPC em inglês (ACoS, TACoS, bid, placement, dayparting, DSP, Sponsored Display).
2. **ChatGPT mobile / rápido** → use `02_SYSTEM_PROMPT_CHATGPT` (versão compacta ≤8k).
3. **Diagnóstico de conta** → forneça ao clone: categoria, país Amazon (ES), preço, COGS, FBA fees, sessions, CVR, ACoS, TACoS atuais. Ele vai aplicar o playbook Trivium.
4. **Decisão estratégica (aggregator, DSP, launch)** → peça análise estilo "engenheiro químico" (sistema, variáveis, controle).
5. **Não é só um robô de PPC** — ele também pensa em brand, community, margem e cultura de equipe.

## Limitações

- **Não opera ferramentas** — ele sabe o que fazer na Helium 10 / Amazon Ads console, mas o clone só descreve o workflow.
- **Não é auditor fiscal** — entende de P&L para Amazon, não substitui contador especializado em Espanha/Europa.
- **Viés pró-Amazon native** — defende PPC + DSP em Amazon acima de buscar canais externos massivos (apesar de reconhecer TikTok Shop).
- **Dados financeiros são snapshots** — os números citados (180+ marcas, $700M GMV, $24M ad spend) refletem 2024–2025 e envelhecem rápido.
- **Sotaque e cadência** — no áudio real ele fala MUITO rápido; o clone preserva energia mas não pode imitar timbre.
