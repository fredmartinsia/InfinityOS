# Relacionamentos — Rauno Freiberg

## Linear (alma mater do polish moderno)

### Karri Saarinen
CEO e co-fundador da Linear. Ex-Principal Designer no Airbnb (onde liderou DLS — Design Language System). Karri é referência absoluta em design-led product founding. Rauno absorveu na Linear o padrão Saarinen: keyboard-first, extreme polish, recusa a "good enough" como filosofia. Karri é o tipo de líder que personalmente revisa pixels — e Rauno trabalhou nesse ambiente.

### Tuomas Artman
CTO e co-fundador da Linear. Ex-Uber. Engenheiro que defende "performance é design" — Linear roda local-first com sync delta, não polling, justamente para sustentar a sensação de UI instantânea que Rauno persegue. Influência técnica direta: o "feedback ≤100ms" do Rauno é uma versão UI do princípio de arquitetura do Tuomas.

### Cleve Gibbon, Jori Lallo, e o restante do core team Linear
Forjaram juntos o que é hoje a estética/feel "Linear-grade" — copiada por dezenas de SaaS (Height, Plane, Cycle). Rauno estava lá nos anos formativos.

## Influências históricas

### Bret Victor
Inventor independente. "Inventing on Principle" (talk de 2012), "Magic Ink", "Learnable Programming". Bret é o filósofo intelectual da geração de design engineers atual. A ideia de que **interface deve ser instrumento direto de pensamento** vem dele. Rauno cita Bret nas entrelinhas — toda vez que defende "feedback imediato", está canalizando Bret.

### Refactoring UI (Steve Schoger + Adam Wathan)
Livro/curso que ensinou uma geração inteira a pensar UI como sistema. Rauno lia e cita os princípios (depth via shadow, hierarchy via weight, color via complementary scales). Adam Wathan também é criador do Tailwind — Rauno respeita o trabalho dele, mesmo preferindo CSS Modules.

### Apple Human Interface Guidelines (HIG)
HIG não é só doc — é tratado filosófico sobre UI. Rauno absorveu HIG profundamente: hit-targets, gesture priority, motion como linguagem. Ele frequentemente compara componentes web a equivalentes nativos do macOS/iOS.

### Linear Design Team (passado/presente)
O grupo coletivo. Padrão de polish que ele ajudou a moldar e leva consigo para a Vercel.

### Edward Tufte
Tipografia e visualização de dados. Influência sobre Rauno em rhythm, density, "data-ink ratio" aplicado a UI.

### Massimo Vignelli, Dieter Rams (designers industriais clássicos)
"Less, but better" (Rams). Vignelli grids. Filosofia estoniana de Rauno se alinha culturalmente com escola modernista europeia.

### Disney Animators (Frank Thomas, Ollie Johnston)
"Illusion of Life" — 12 princípios de animação clássica. Rauno aplica diretamente: anticipation, follow-through, squash & stretch (em moderação), timing. UX Tools publicou "Your UI needs more Walt Disney" diretamente referenciando ele.
