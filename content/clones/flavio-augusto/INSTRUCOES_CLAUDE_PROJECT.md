# Instruções: Como Criar Claude Project - Flávio Augusto

> Guia passo a passo para criar o Claude Project com o clone do Flávio Augusto

---

## 📋 Pré-requisitos

- Conta Claude Pro ou Team
- Acesso ao claude.ai
- Todos os 12 arquivos do clone (já criados e renomeados)

---

## 🚀 Passo a Passo

### Passo 1: Acesse Claude.ai e Crie Novo Projeto

1. Vá para https://claude.ai
2. No menu lateral esquerdo, clique em **"Projects"**
3. Clique em **"Create Project"** (botão no canto superior direito)
4. Nome do projeto: **"Clone Flávio Augusto"**
5. Descrição (opcional): "Clone digital de Flávio Augusto da Silva - Empreendedor, fundador Wise Up, criador Geração de Valor"

### Passo 2: Configure as Custom Instructions (System Prompt)

1. Dentro do projeto, clique em **"Project Settings"** ou **"Custom Instructions"**
2. Abra o arquivo: `flavio-augusto_02_SYSTEM_PROMPT_CLAUDE.md`
3. **Copie TODO o conteúdo** do arquivo
4. **Cole** no campo "Custom Instructions" ou "Project Instructions"
5. Clique em **"Save"**

**Arquivo a usar:** `flavio-augusto_02_SYSTEM_PROMPT_CLAUDE.md`

**⚠️ IMPORTANTE:**
- Use a versão **CLAUDE**, NÃO a versão ChatGPT
- O arquivo Claude tem ~33k caracteres (completo)
- A versão ChatGPT é limitada a 8k caracteres

---

### Passo 3: Adicione os Arquivos de Knowledge Base

Agora você vai adicionar **10 arquivos** como knowledge base (todos EXCETO os 2 system prompts).

**Arquivos para adicionar (em ordem):**

1. ✅ `flavio-augusto_01_README.md`
2. ✅ `flavio-augusto_03_PROFILE_COMPLETE.md`
3. ✅ `flavio-augusto_04_PSYCHOLOGY_COMPLETE.md`
4. ✅ `flavio-augusto_05_COMMUNICATION_COMPLETE.md`
5. ✅ `flavio-augusto_06_KNOWLEDGE_COMPLETE.md`
6. ✅ `flavio-augusto_07_THINKING_COMPLETE.md`
7. ✅ `flavio-augusto_08_RELATIONSHIPS.md`
8. ✅ `flavio-augusto_09_CONTEXT.md`
9. ✅ `flavio-augusto_10_EXAMPLES.md`
10. ✅ `flavio-augusto_11_SOURCES.md`

**❌ NÃO adicionar:**
- `flavio-augusto_02_SYSTEM_PROMPT_CHATGPT.md` (esse é para GPTs, não Claude)
- `flavio-augusto_02_SYSTEM_PROMPT_CLAUDE.md` (esse já foi usado nas Custom Instructions)

**Como adicionar:**

1. No projeto Claude, procure seção **"Project Knowledge"** ou **"Add Knowledge"**
2. Clique em **"Upload Files"** ou ícone de upload
3. Selecione os **10 arquivos** listados acima
4. Aguarde upload completar (pode demorar alguns segundos)
5. Verifique que todos os 10 arquivos aparecem na lista

**Limite Claude:** Claude Projects aceitam até 20 arquivos, então você está usando apenas 10 (metade do limite).

---

### Passo 4: Teste o Clone

Agora teste se o clone está funcionando corretamente.

**Testes recomendados:**

**Teste 1: Identidade**
```
Pergunta: "Quem é você?"
Resposta esperada: Deve se apresentar como Flávio Augusto, mencionar Wise Up, origem humilde, etc.
```

**Teste 2: Comunicação**
```
Pergunta: "Como começar a empreender sem dinheiro?"
Resposta esperada: Deve provocar, contar história dos R$ 20 mil de dívida, usar framework Visão+Coragem+Competência
```

**Teste 3: Filosofia**
```
Pergunta: "Qual sua filosofia de vida?"
Resposta esperada: Visão + Coragem + Competência, explicar cada pilar com exemplos
```

**Teste 4: História Pessoal**
```
Pergunta: "Conte sobre a expulsão do Colégio Naval"
Resposta esperada: História completa, transformação de fracasso em combustível, lição aprendida
```

**Teste 5: Citações**
```
Pergunta: "O que você pensa sobre dinheiro?"
Resposta esperada: "Quem trabalha só por dinheiro nunca será rico. Rico é quem cria valor."
```

## 🔧 Solução de Problemas

### Problema: Clone não está se comportando como Flávio

**Solução:**
1. Verifique se Custom Instructions têm o conteúdo do arquivo CLAUDE (não ChatGPT)
2. Confirme que todos os 10 arquivos de knowledge base foram adicionados
3. Teste com perguntas específicas (veja seção Testes acima)

### Problema: Respostas muito genéricas

**Solução:**
1. Seja específico nas perguntas
2. Peça exemplos ou histórias pessoais
3. Mencione Wise Up, Orlando City, ou Geração de Valor
4. Exemplo: "Flávio, como VOCÊ lidou com medo quando fundou a Wise Up?"

### Problema: Clone não usa citações autênticas

**Solução:**
1. Verifique que arquivo `flavio-augusto_05_COMMUNICATION_COMPLETE.md` foi adicionado
2. Peça diretamente: "Qual sua citação sobre dinheiro?" ou "O que você diz sobre coragem?"
