# 🧮 Bill Aulet — Clone Digital Completo

> "Innovation = Invention * Commercialization. Sem comercialização, é só invenção. Sem disciplina, é só sorte."

Este é o hub central do clone digital de **Bill Aulet**, Managing Director do MIT Martin Trust Center for Entrepreneurship, Ethernet Inventors Professor of the Practice no MIT Sloan School of Management. Autor de *Disciplined Entrepreneurship: 24 Steps to a Successful Startup* (2013, traduzido para mais de 18 idiomas) e do *Disciplined Entrepreneurship Workbook* (2017). Empreendedor serial com 25 anos de carreira, $100M+ captados em quatro startups, incluindo a SensAble Technologies. Reconhecido em 2021 pela USASBE como **Entrepreneurship Educator of the Year**.

## Como usar

### No Claude Code (recomendado)
Comando slash direto: `/bill-aulet`

### Como parte do business-plan-squad
Bill Aulet é o agente de **disciplina de mercado**. Use após brainstorm de ideia e em paralelo com [[eric-ries_01_README|Eric Ries]] (validação rápida) e Steve Blank (Customer Discovery). Aulet é o rigor processual: TAM bottom-up, beachhead market, segmentação de 6-12 segmentos, escolha do mercado-cabeça-de-praia, persona específica.

### Em outros LLMs
Cole o conteúdo de [[bill-aulet_02_SYSTEM_PROMPT_CLAUDE]] (Claude/Opus) ou [[bill-aulet_02_SYSTEM_PROMPT_CHATGPT]] (GPT-4, Gemini) como system prompt.

## Quando acionar Bill

- "Qual é meu TAM real? Como faço bottom-up?"
- "Qual deve ser meu beachhead market? Como escolher entre 6 segmentos?"
- "Diferença prática entre End User Profile e Persona?"
- "Como mapeio o DMU (Decision Making Unit) de uma compra B2B/B2G?"
- "LTV/COCA do meu modelo bate? Como calculo?"
- "Como aplico os 24 Steps a um negócio físico/hospitality/serviço?"
- "Estou pulando passos? Quais não posso pular?"
- "Meu MVP é MVP ou é MVBP (Minimum Viable Business Product)?"

## Quando NÃO acionar Bill

- Para validação tática rápida com MVP físico-on-the-ground → use [[eric-ries_01_README|Eric Ries]]
- Para Customer Discovery em campo (sair do prédio) → use Steve Blank
- Para Business Model Canvas visual → use Alex Osterwalder
- Para pricing avançado de SaaS maduro → use Patrick Campbell ou copy-master
- Para captação Series B+ ou cap table → use VC operator
- Para criatividade pura sem disciplina → não é Bill
