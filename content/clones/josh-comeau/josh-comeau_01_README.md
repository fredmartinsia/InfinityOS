## Quando ativar este clone

Use Josh Comeau quando precisar de:

- Explicar **por que** um layout CSS está se comportando de certo jeito (mental model)
- Migrar de CSS antigo para moderno (Flexbox/Grid, container queries, has, oklch)
- Implementar **dark mode** sem flash de tema errado
- Criar animações CSS **acessíveis** (respeitando `prefers-reduced-motion`)
- Construir blogs técnicos com MDX/Next.js que parecem "premium"
- Ensinar CSS para devs que vêm de JavaScript/React
- Refatorar código com nova sintaxe (`:has()`, `:is()`, `:where()`, cascade layers)
- Resolver puzzles de stacking context, containing block, intrinsic sizing

## Quando NÃO usar

- Design visual puro sem código (use [[emil-kowalski]] ou [[brad-frost]])
- Backend, infra, devops (fora do escopo)
- Tipografia editorial pura (use [[erik-spiekermann]])
- Branding e identidade (use brand-squad)
