## Linha do tempo

### 2007 — Início
Adolescente em casa, mexendo com HTML e CSS pela primeira vez. Cria sites de bandas e projetos pessoais. Fica viciado em ver código vivo no browser.

### Início dos anos 2010 — Concordia & primeiros trabalhos
Estuda em Montreal, mas o que importa mesmo é a prática. Acaba ensinando fundamentos de web development na **Concordia University** — um sinal precoce do que vai virar a vocação central dele.

### Khan Academy
Entra como engineer na **Khan Academy**, organização sem fins lucrativos focada em educação acessível. Trabalha em produto educacional. É aqui que a paixão por **ensinar bem** se solidifica — Khan Academy tem cultura forte de mental models e explicações progressivas, e isso marca Josh para sempre.

### DigitalOcean
Sai da Khan Academy e vai pra **DigitalOcean** como senior engineer no time de produto. Trabalha em interfaces complexas, design systems internos. A escala maior expõe Josh a problemas reais de performance, acessibilidade e consistência em scale.

### Gatsby (depois adquirida pela Netlify)
Junta-se à **Gatsby** — na época, um dos frameworks mais quentes do ecossistema React. Trabalha em produto. Vê de perto como SSG, MDX e o ecossistema Jamstack se desenvolvem. A experiência com MDX vira a base técnica do que viria a ser joshwcomeau.com.

### 2018–2019 — O blog começa a crescer
Josh começa a publicar artigos no próprio site enquanto trabalha em Gatsby. Os artigos têm uma assinatura imediatamente identificável: demos interativos construídos à mão, explicações em camadas, mental models antes de propriedades. A "Interactive Guide to Flexbox" estoura — vai parar no topo do Hacker News, vira referência mundial.

### 2020 — Independente
Em 2020, Josh **vira indie**. Sai da carreira corporativa e foca em criar **CSS for JavaScript Developers**, seu primeiro curso premium. O curso lança e é um sucesso retumbante: milhares de alunos, ~$500 por seat, comunidade engajada no Discord.

### 2023 — The Joy of React
Lança o segundo curso, **The Joy of React** (joyofreact.com). Mesma filosofia: mental model primeiro, exercícios progressivos, polish no final. Atualiza para React v19 e cobre **React Server Components** com profundidade rara no mercado de cursos.

### 2024–2026 — Smashing, conferências, autoridade
Speaker recorrente em **SmashingConf** (NY 2024, SF 2023), **FITC**, e outras conferências de front-end. Author no **Smashing Magazine**. Aparições em podcasts (**Scrimba Podcast**, **Reactiflux**). Cria o utilitário **Operator Lookup** (joshwcomeau.com/operator-lookup) — uma ferramenta lúdica para devs JS pesquisarem operadores. Blog passa de **200k leitores mensais**.

## Cursos

### CSS for JavaScript Developers (css-for-js.dev)

- **Lançado:** 2020
- **Preço:** ~$500 USD (com tiers)
- **Alunos:** dezenas de milhares
- **Filosofia:** ensinar CSS pra devs JavaScript pelos princípios — passar pelos layout modes um por um, construindo mental models. **Não memorizar snippets, entender princípios para construir qualquer layout.**
- **Formato:** vídeo + texto + exercícios + workshops + Discord ativo

### The Joy of React (joyofreact.com)

- **Lançado:** 2023
- **Atualização:** React v19, com cobertura extensiva de React Server Components
- **Filosofia:** construir intuição de como React funciona, para que o aluno consiga construir aplicações ricas e dinâmicas
- **Diferencial:** mental model primeiro, hooks no contexto certo, RSC explicado sem jargão

### Bundle: Joy for JavaScript Developers
Os dois cursos juntos com desconto.

## O que diferencia Josh

A maioria dos educadores de CSS faz **referência** (lista de propriedades). Josh faz **pedagogia** (mental models que se transferem). É a diferença entre dar peixe e ensinar a pescar — e ele é dos poucos que conseguem ensinar a pescar **e** fazer parecer divertido.
